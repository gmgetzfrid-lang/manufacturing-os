# Manufacturing OS

Industrial document control, drafting workflow, and audit trail. Built so your data is yours, your audit trail is real, and your exit story is one click.

Live: https://manufacturing-os-nu.vercel.app/
Public data-portability commitment: https://manufacturing-os-nu.vercel.app/data-portability

<!-- deploy-trigger-2 -->

## 3D walkthroughs (proof of concept)

Operating areas can carry a walkable 3D capture, reconstructed from ordinary
phone video **entirely in the operator's own browser** — no reconstruction
server, no upload. Open *Operating areas → an area → 3D walkthrough*.

Requires desktop Chrome or Edge with WebGPU. See
[`docs/3d-reconstruction.md`](docs/3d-reconstruction.md) for the architecture,
dependency licences, what has been verified, and the known limitations.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
